# Research Expression Engine Playbook

## Agent Summary

This playbook explains how ResearchOS supports writing, talks, proposals, figures, and public profiles. It should diagnose the research judgment before polishing language. Expression tasks should preserve evidence boundaries and separate candidate wording from confirmed claims.

## Expression Chain

```text
Task intent -> audience -> evidence boundary -> core judgment -> expression strategy -> candidate text/structure -> validation
```

## Use When

- writing a paper section;
- creating a talk outline;
- drafting a proposal or research statement;
- designing a figure;
- turning cards into a public-safe narrative.

## Do Not Use For

- inventing facts;
- turning private/local-only material into public text;
- polishing without checking whether the claim is valid.

## Output Format

```text
Judgment:
Audience and purpose:
Evidence boundary:
Expression strategy:
Candidate text / structure:
Risks:
Next action:
```
