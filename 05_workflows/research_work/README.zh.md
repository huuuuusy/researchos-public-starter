# 日常研究工作流

这里是日常研究工作的简短方法：读论文、写论文、审稿、写申请、会后跟进、指导学生、考虑换题、准备报告和配图，以及事后复盘。每份都写明助手在读取档 quick、standard、evidence 分别读你的哪些卡，按什么步骤做，你会得到什么，哪些部分要等你确认。表中的路线 id 就是 `python3 scripts/plan_context.py <路线 id> --vault personal_vault` 里填的那个。

| 工作流 | 什么时候用 | 路线 id |
| --- | --- | --- |
| [读论文](paper-reading.zh.md) | 把一篇论文、报告或一章书整理成论文卡 | `material_understanding` |
| [写论文](paper-writing.zh.md) | 起草或修改自己论文的某一节 | `paper_writing` |
| [审稿](peer-review.zh.md) | 替别人审稿件、学位论文章节或申请书 | `peer_review` |
| [写基金申请](grant-proposal.zh.md) | 构思或起草经费申请 | `proposal` |
| [会后跟进](meeting-follow-up.zh.md) | 把会议笔记整理成决定、待办和卡片更新 | `meeting_follow_up` |
| [给学生的反馈](mentee-feedback.zh.md) | 回应学生的草稿、计划或进展汇报 | `mentee_feedback` |
| [要不要换题](topic-change.zh.md) | 决定项目继续、收窄、转向还是放弃 | `idea_diagnosis` |
| [报告与作图](talks-and-figures.zh.md) | 准备报告、幻灯片、海报或论文配图 | `presentation`、`figure_design` |
| [复盘](retrospective.zh.md) | 回头看一次投稿、没批下来的申请、失败的实验或卡住的修改 | `system_reflection` |
