# 工作流层

保存可复用的公开工作流，例如材料接入、候选确认、Agent handoff、验证和自我进化。核心工作流位于 `research_management/`：

- `material-intake-workflow.md`：材料进入 ResearchOS 的 M1 登记流程。
- `asset-type-extension-workflow.md`：新增资产类别、资源对象、工作流对象或 dashboard 盒子的扩展流程。
- `material-analysis-lifecycle-standard.md`：M1/M2/M3 材料理解成熟度。
- `task-to-context-matrix.md`：任务到上下文的路由矩阵。
- `ai-agent-collaboration-workflow.md`：用户、Codex GUI/CLI 和其他 Agent 的协作协议。
- `group-composition-lifecycle-standard.md`：G0/G1/G2 卡片组合和关系卡片规范。
- `new-project-intake-workflow.md`：早期想法进入项目接收台的流程。
- `research-expression-engine-playbook.md`：论文、报告、proposal、图表和公开叙事的表达工作流。
- `self-evolution-workflow.md`：ResearchOS 自我审计和候选优化流程。
