# 认知方法层

这一层记研究者怎样做事、怎样推理，和材料、解释、候选判断分开。公开 starter 里这一层是空的；在你自己的库里，用 `personal_vault/` 下的同名文件夹，放三类卡：

- `style/`：风格卡，一类任务一张（`writing.md`、`review.md`、`proposal.md`、`figures-talks.md`、`mentoring.md`）。助手做哪类任务，就在 quick 层读对应的那张。骨架：[`style.zh.md`](../09_templates/basic/style.zh.md)；示例：[写作做法](../examples/starter-cards/zh-CN/03_cognition/style/writing.md)。
- `heuristics/`：做研究的习惯。骨架：[`heuristic.zh.md`](../09_templates/basic/heuristic.zh.md)；示例：[启发式卡](../examples/starter-cards/zh-CN/03_cognition/heuristics/check-benchmark-version-first.md)。
- `mental_models/`：你对领域里某件事怎样运作的理解。骨架：[`mental-model.zh.md`](../09_templates/basic/mental-model.zh.md)。

这些卡写的是你的做法，所以助手可以根据你自己的材料起草，但要你同意后才写进来。
