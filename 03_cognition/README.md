# Cognition Layer

This layer is where a vault keeps the researcher's own judgment rules, heuristics and mental models, separate from materials, interpretation and candidate judgment. The public starter ships it empty: what goes here is personal, and it is written only after the researcher confirms it. In your own vault, use the same folder under `personal_vault/`.
