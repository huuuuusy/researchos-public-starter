# Cognition Layer

This layer holds how the researcher works and reasons, kept apart from materials, interpretation and candidate judgments. The public starter ships it empty; in your own vault, use the same folder under `personal_vault/`, with three kinds of card:

- `style/`: working-style cards, one per kind of task (`writing.md`, `review.md`, `proposal.md`, `figures-talks.md`, `mentoring.md`). An assistant reads the matching card at the quick level of that task. Skeleton: [`style.md`](../09_templates/basic/style.md); example: [writing style](../examples/starter-cards/en/03_cognition/style/writing.md).
- `heuristics/`: working habits. Skeleton: [`heuristic.md`](../09_templates/basic/heuristic.md); example: [heuristic card](../examples/starter-cards/en/03_cognition/heuristics/check-benchmark-version-first.md).
- `mental_models/`: how you think something in your field works. Skeleton: [`mental-model.md`](../09_templates/basic/mental-model.md).

These cards describe how you work, so an assistant may draft them from your own material but writes them only after you agree.
