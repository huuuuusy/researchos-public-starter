# 用户接入笔记示例

这是一个虚构示例。真实使用前，请把每个回答替换成你自己的公开安全信息。

## 身份信息

| 问题 | 示例回答 |
| --- | --- |
| 你是谁？用一段话描述。 | 我是虚构研究者Sue 博士，研究人类确认的 AI 研究工作流、证据边界和公开安全知识系统。 |
| 公开主页 | `https://example.org/sue` |
| Google Scholar 或 ORCID | `https://scholar.example.org/sue` |
| 公开简历或简历摘要 | `materials/sue-public-cv-summary.md` |
| 三个长期主题 | 人类确认、证据有界的 AI 协助、研究工作流记忆。 |
| 绝对不能导出的材料 | 私人笔记、学生信息、未公开论文、账号令牌、本地运行日志。 |

## 第一篇论文

| 字段 | 示例回答 |
| --- | --- |
| 标题 | Calibrated Memory Workflows for Human-AI Research Notes |
| 年份 | 2026 |
| 作者 | Sue、合作者 A、合作者 B |
| 公开来源 | `https://example.org/papers/calibrated-memory-workflows` |
| 为什么先读它 | 它展示核心流程：材料变成候选内容，候选内容需要确认，已确认表述才进入可复用状态。 |

## 第一个报告

| 字段 | 示例回答 |
| --- | --- |
| 标题 | From Notes to Confirmed Research Memory |
| 日期 | 2026-04-18 |
| 听众 | 虚构研究生研究方法研讨课 |
| 公开来源 | `https://example.org/talks/confirmed-research-memory` |
| 为什么先读它 | 它把论文想法转成更容易理解的工作流叙事。 |

## 第一个计划

| 字段 | 示例回答 |
| --- | --- |
| 目标 | 建立一个公开安全启动流程，帮助新研究者创建前五张卡片。 |
| 第一个验证检查 | 把调度器示例复制到 `personal_vault/`，把其中的承诺换成这个计划，确认 `python3 scripts/ros.py --root personal_vault today` 列出了它。 |
| 第一个阻塞点 | 需要更清晰的卡片成熟度示例。 |

## Agent Summary

一份虚构接入笔记，展示用户在生成个人、论文、报告、合作者和计划卡片前应提供的第一批回答。
