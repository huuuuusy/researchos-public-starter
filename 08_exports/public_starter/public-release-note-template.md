# Public Release Note Template

## Agent Summary

Use this template to state exactly what a public ResearchOS release includes, excludes, and permits. Replace release-specific details without weakening privacy, evidence, or license boundaries.

## Release Purpose

This release demonstrates the public-safe mechanisms of ResearchOS: structural alignment, candidate confirmation, agent handoff, dashboard demo, and pre-release validation.

## Included

- Public-safe directory structure.
- Fictional demo materials.
- Local dashboard and demo data.
- Provider/runtime example configuration.
- Chinese and English documentation.

## Excluded

- Non-public research memory.
- Real people, students, collaborators, or reviewer materials.
- Unpublished manuscripts, grant materials, or internal strategy.
- Raw corpus, runtime logs, local paths, or API keys.
