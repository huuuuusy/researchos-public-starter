# 公开发布说明模板

## Agent Summary

本模板用于明确一次公开 ResearchOS 发布包含什么、不包含什么以及允许怎样使用。替换具体版本信息时，不得削弱隐私、证据或许可边界。

## 发布目的

本次发布展示 ResearchOS 的公开安全机制：结构同构、候选确认、agent handoff、dashboard demo 和发布前验证。

## 包含内容

- 公开安全的目录结构。
- 虚构 demo materials。
- 本地 dashboard 和 demo data。
- provider/runtime 示例配置。
- 中英文文档。

## 不包含内容

- 非公开研究记忆。
- 真实人物、学生、合作者或评审材料。
- 未公开论文、申请材料或内部策略。
- 原始 corpus、运行日志、本地路径或 API keys。

## 许可

本项目允许个人学习、个人研究、学术研究、教学、非商业评估，以及非商业学术再分发或二次开发。商业使用、托管服务、打包衍生版本，或具有商业化潜质的大规模分发，需要事先取得 Shiyu Hu 的书面许可。
