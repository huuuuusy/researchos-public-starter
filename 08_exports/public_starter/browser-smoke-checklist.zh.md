# 浏览器 Smoke Check 清单

启动 dashboard 后，用这份清单确认本仓库展示的是 demo 数据，而不是非公开内容。

| 区域 | 操作 | 通过标准 |
| --- | --- | --- |
| 工作台 | 打开 dashboard，从目标、链接/路径或文件名建立一项任务。 | 当前 Work Session 出现在建议之前，且不会直接成为长期记忆。 |
| 工作台结果 | 提交一个目标和来源，再继续追问。 | 显示完整可复制任务包；不启动本机或远程执行，也不强制生成文件。 |
| 资产 | 全局搜索一张 demo 卡片，点击“用于当前任务”。 | 卡片加入工作牌组，不创建重复待确认事项。 |
| 待确认 | 点击“提出写回”后修改目标或牌组，再完成本轮。 | 只有拟议长期变化进入待确认；完成后进入历史。本仓库的持久写回动作仍只允许复制。 |
| 语言 | 切换页面语言后刷新。 | UI 文案变化且 Work Session 保留；不重新生成时，活跃 prompt/模板语言不变。 |
| 边界 | 检查工作台、待确认控件和浏览器 console。 | 本仓库保持 copy-only；不出现本机/远程 provider、任意命令、持久写回、私人路径或 console error。 |
| 手机端 | 在 `390 x 844` 下重复三个主页面。 | 文字和控件不重叠，页面没有横向溢出。 |

发现真实敏感内容、本地路径、API key 或非公开项目状态时，停止发布并回到 safe export review。
