# Archive Layer

Stores deprecated or historical public-safe materials. Archiving does not grant public permission; sensitive content still does not belong here.

- `task_artifacts/`: completed bounded work products whose feedback or decision context remains independently useful.
- Project-level research plans, runtime evidence, and technical-report history remain separate archive classes.
- Public release history belongs in `docs/releases/`. Private ResearchOS system audits are not mirrored into this repository; only public-safe evidence with an independent maintenance purpose may be archived here.
- [Public Core Skill Migration Audit 2026-06-27](public-core-skill-migration-audit-2026-06-27.md): public-safe receipt for a completed migration; historical evidence only.

See [Derived Work Artifact Lifecycle](../05_workflows/research_management/derived-work-artifact-lifecycle.md).
