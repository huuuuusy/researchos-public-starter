# 阶段性任务产物归档

本目录用于已经结束、且公开安全的一次性 PPT、会议、申请、分析或 revision 工作产物示例。public starter 有意不包含任何真实任务产物。

只有当完整文档保存了最终成品或 Git 历史无法替代的反馈、取舍或历史语境时，才使用本目录。归档状态不等于公开许可。真实人物、未公开工作、申请、审稿、本机路径和私人策略只能留在用户自己的私人/本地 vault。

当前状态必须从 `01–06` 层读取，不能从归档快照推断。

参见[阶段性派生工作产物生命周期](../../05_workflows/research_management/derived-work-artifact-lifecycle.zh.md)。
