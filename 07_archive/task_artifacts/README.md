# Archived Task Artifacts

This directory is the route for completed, public-safe examples of bounded presentation, meeting, application, analysis, or revision work products. The tracked public starter intentionally contains no real task artifacts.

Use this directory only when a complete artifact retains feedback, tradeoff, or historical context that a final output or Git history cannot replace. Archive status does not grant publication permission. Real people, unpublished work, applications, reviews, local paths, and private strategy belong only in the user's private/local vault.

Current state must be read from layers `01–06`, not inferred from an archived snapshot.

See [Derived Work Artifact Lifecycle](../../05_workflows/research_management/derived-work-artifact-lifecycle.md).
