# 归档层

保存已弃用或历史化的公开安全材料。归档不等于公开许可，敏感内容仍然不能进入这里。

- `task_artifacts/`：已经结束、但反馈或决策语境仍有独立价值的一次性工作产物。
- 项目级研究计划、运行证据和技术报告历史继续使用各自独立的归档类别。
- 公开版本历史放在 `docs/releases/`。私有 ResearchOS 的系统审计不镜像到本仓库；只有公开安全且具有独立维护价值的证据才进入这里。
- [Public Core Skill 迁移审计 2026-06-27](public-core-skill-migration-audit-2026-06-27.md)：已完成迁移的公开安全回执，仅作历史证据。

参见[阶段性派生工作产物生命周期](../05_workflows/research_management/derived-work-artifact-lifecycle.zh.md)。
