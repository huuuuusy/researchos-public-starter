# ResearchOS Public Starter V1.0.4

Status: release candidate, not yet released. The latest release is `v1.0.3`.

## What Changed

The first run was retested with a fictional psychology researcher who has never used a terminal, Python or an AI assistant, and rewritten where that user got stuck. The technical report is unchanged.

- The README now says what is needed before starting (an assistant that can run commands, its paid plan and regional availability, Python 3.10 or newer, confirmation prompts) and where the user's material goes: cards stay on the computer and are not pushed, but what the assistant reads is sent to its provider, synced folders upload the vault, and nothing backs it up. It lists what must not be given to the assistant, such as raw participant or client data.
- The First Run in `AGENTS.md` has seven steps. The new sixth step turns the user's current view into one judgment, so that a later change to a paper card brings it back for review; the assistant explains the output in plain words instead of pasting it, accepts a publication list in any form and maps phases such as ethics approval and data collection to `lifecycle_phase` values. The daily loop says how to keep, revise or replace a judgment after a source changes.
- The first-run guide adds a worked example in psychology: a study included in a meta-analysis is retracted, and the judgment that rests on it comes back.
- The manual's glossary explains the sensitivity labels and what `ros context` leaves out.
- `ros_demo.py --init` now adds `00_identity` and `04_people` to the vault's graph roots, so `ros` sees the profile and collaborator cards. `ros rules --check` no longer ends with a colon when it finds no problems.

[V1.0 release notes](v1.0.0.md) remain the record of what V1.0 includes and what remains limited.
