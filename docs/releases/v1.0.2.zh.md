# ResearchOS Public Starter V1.0.2

状态：已于 2026-10-30 以 `v1.0.2` 发布。这是一次文档发布，`v1.0.1` 的软件行为没有变化。

## 改了什么

- 技术报告 V11，[英文 PDF](../technical-report.en.pdf) 31 页，[中文 PDF](../technical-report.zh.pdf) 27 页。外部审阅发现报告同时讲两个主张，V11 因此收窄到原型能够支撑的一个：来源变化时，系统沿记录下来的依赖把判断交回研究者。
- 报告改为八节。有界目标、组合、两条命题和四个历史请求移入补充说明。
- 术语改为事项、证据、依据、待答、延期。`ros` 命令输出仍用原有说法，报告附录 A 有说明。
- 第 2 节写明了复核如何关闭，第 7 节为比较增加一组对照：强 AI 模型配带依据版本的判断块。
- 报告和文档不再区分私有版与公开版。
- 图重建为 `researchos-r11-*`，用户手册、README 和动图也改用新术语。

报告描述的仍是附录 B.3 列出的提交上的原型。比较和使用研究都还没有进行。[V1.0 发布说明](v1.0.0.zh.md)仍是 V1.0 包含什么、还有哪些局限的记录。
