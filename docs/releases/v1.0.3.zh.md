# ResearchOS Public Starter V1.0.3

状态：已于 2026-10-30 以 `v1.0.3` 发布。这是一次文档发布，`v1.0.2` 的软件行为没有变化。

## 改了什么

技术报告 V11 经过三项独立核对后作了修正：按报告完整运行示范会话，逐段比对中英文，并对照原文核对引用。[英文 PDF](../technical-report.en.pdf) 31 页，[中文 PDF](../technical-report.zh.pdf) 27 页。

- 报告不再称自己的做法为第三种：需求追踪和活体综述已把变化交回给人，报告主张的是把这种交回做到单条研究判断上。
- 关于事项如何关闭、审阅期间依据变化如何处理的说法已与代码一致。
- 第 6 节、表 4 以及图 9、10 中关于 AI 科学家系统的说法已与其论文所报告的内容一致。
- 第 6、7 节的文献表述已按原文收紧。

比较和使用研究都还没有进行。[V1.0 发布说明](v1.0.0.zh.md)仍是 V1.0 包含什么、还有哪些局限的记录。
