# ResearchOS Public Starter V1.0.4

状态：候选版本，尚未发布。最新发布版是 `v1.0.3`。

## 改了什么

首次上手按一位虚构的心理学研究者重新试跑：她没用过终端、Python 或 AI 助手。凡是她卡住的地方都改写了。技术报告没有改动。

- README 写明了开始前要准备什么（能运行命令的助手、它的付费订阅与可用地区、Python 3.10 或更高版本、确认弹窗），以及用户的材料会去哪里：卡片留在电脑上、不会被推送，但助手读到的内容会发给它的服务商，同步文件夹会上传库，也没有自动备份。README 还列出了不能交给助手的东西，例如被试或来访者的原始数据。
- `AGENTS.md` 的 First Run 改为七步。新增的第 6 步把用户眼下的看法写成一条判断，以后论文卡片一变，它就会回来等复核。助手用平常话转述输出、不原样粘贴，接受任何形式的发表清单，并把伦理审批、数据收集这类阶段对应到 `lifecycle_phase` 的取值。日常用法写明了来源变化后如何保留、修改或替换一条判断。
- 首次上手说明加了一个心理学例子：元分析纳入的一项研究被撤稿，依赖它的判断回来等复核。
- 用户手册的词表解释了敏感性标签，以及 `ros context` 不打包哪些内容。
- `ros_demo.py --init` 现在把 `00_identity` 和 `04_people` 加进库的扫描范围，`ros` 能看到档案卡和合作者卡。`ros rules --check` 没有问题时，最后一行不再以冒号结尾。

[V1.0 发布说明](v1.0.0.zh.md)仍是 V1.0 包含什么、还有哪些局限的记录。
