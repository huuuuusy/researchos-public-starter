# ResearchOS Public Starter V1.0.1

Status: released as `v1.0.1` on 2026-10-30. It is a documentation release: the software behaviour of `v1.0.0` is unchanged.

## What Changed

- Technical report V10, with a 39-page [English PDF](../technical-report.en.pdf) and a 33-page [Chinese PDF](../technical-report.zh.pdf). It opens with the research scenario, the pain and why the design follows, shows a worked session in Section 2, and then gives principles, definitions, architecture and gaps, and comparison. Figures 2-9 and Tables 2-3 are renumbered, and "model" now means only an AI model. Its claims are unchanged, apart from one added comparison in Section 6.1 and Table 5.
- README opening, how-to-cite section and `CITATION.cff` with the Zenodo DOI.
- First-run fixes from a fresh-clone walk-through.
- `.zenodo.json` declares the non-commercial license, so the archive record no longer falls back to a default license.

The report still describes the prototype at the commits it names in Appendix B.3. [V1.0 release notes](v1.0.0.md) remain the record of what V1.0 includes and what remains limited.
