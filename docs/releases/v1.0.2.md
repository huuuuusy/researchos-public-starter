# ResearchOS Public Starter V1.0.2

Status: released as `v1.0.2` on 2026-10-30. It is a documentation release: the software behaviour of `v1.0.1` is unchanged.

## What Changed

- Technical report V11, with a 31-page [English PDF](../technical-report.en.pdf) and a 27-page [Chinese PDF](../technical-report.zh.pdf). An external review found that the report told two claims at once, so V11 narrows it to the one the prototype supports: when a source changes, the system follows the recorded dependency and hands the judgment back to the researcher.
- The report now has eight sections. Bounded goals, composition, the two propositions and the four historical requests moved to the supplementary notes.
- Terms changed: item, evidence, basis, waiting on the researcher, deferred. The `ros` commands still print their existing words, as Appendix A of the report notes.
- Section 2 now states how a recheck closes, and Section 7 adds a control arm for the comparison: a strong AI model with judgment blocks that carry basis versions.
- The report and the documentation no longer speak of a private and a public edition.
- Figures were rebuilt as `researchos-r11-*`, and the user manual, README and animation follow the new terms.

The report still describes the prototype at the commits it names in Appendix B.3. The comparison and the study of use have not been run. [V1.0 release notes](v1.0.0.md) remain the record of what V1.0 includes and what remains limited.
