# 行为准则

ResearchOS Public Starter 是一个小型独立研究工具项目。围绕它的讨论和协作应该保持谨慎、建设性，并且符合公开安全边界。

## 期望行为

- 讨论研究流程、工具选择或设计取舍时保持尊重。
- 默认善意，但让主张尽量具体、有证据边界。
- 使用公开安全的例子，不提交私人研究数据、未公开工作、个人信息、provider key 或敏感日志。
- 让反馈可执行：说明哪里不清楚、哪里失败、什么信息会更有帮助。
- 尊重本项目关于学术、个人、非商业和商业使用的许可边界。

## 不接受的行为

- 骚扰、侮辱、威胁或人身攻击。
- 公开他人的私人信息或敏感研究材料。
- 在公开 issue 中发布凭证、provider token、漏洞细节或不安全的复现数据。
- 将本项目误称为自主科研系统、生产服务，或 OSI 认证意义上的开源项目。
- 在未取得许可的情况下，用本仓库招揽商业部署、托管服务或大规模再分发。

## 报告方式

对于普通协作和行为问题，请通过你获得项目或 release 信息时的可信渠道联系维护者。

对于安全敏感问题，请不要打开公开 issue；请按 [SECURITY.md](../../SECURITY.md) 处理。

## 执行方式

为了保护公开发布边界，并让项目对研究用户保持有用，维护者在必要时可以编辑或移除不安全内容、关闭 issue、拒绝 pull request，或限制相关参与。

这份行为准则参考了常见开源社区规范，并针对源代码可见的学术研究启动项目做了调整。
