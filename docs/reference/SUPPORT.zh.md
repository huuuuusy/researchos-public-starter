# 支持

本项目希望用户只靠仓库本身就能理解和运行。请先按下面的文档路径阅读；如果仍然不清楚、运行失败或说明不足，再提交问题。

## 查找对应指南

安装、使用、运行方式和发布问题统一从[文档地图](../README.zh.md)进入。贡献要求见[贡献指南](CONTRIBUTING.zh.md)；安全相关问题通过[安全政策](SECURITY.zh.md)规定的渠道报告，不放入公开求助。

## 求助时应提供什么

如果是启动或仪表盘问题，请提供：

- 操作系统；
- Python 版本；
- 你运行的命令；
- 相关端口号；
- 使用的是仪表盘、命令行、图形界面、公开启动模式还是 personal-vault 模式；
- 案例材料是否开启；
- 能说明失败原因的最短脱敏错误输出。

如果是文档问题，请说明你阅读的文件和章节、希望获得什么信息，以及哪一处解释开始变得不清楚。

如果是模型提供方或 Codex 问题，请说明模型提供方名称、使用 public-starter 还是 personal-vault、本机执行是否可用，以及用于检查模型提供方的命令。不要提供令牌或凭据。

任何求助都不要附带凭据、私人研究记忆、个人数据或未公开材料。

## 支持边界

本项目可以支持：

- 本仓库 的安装和启动问题；
- 示例专用脚本、验证脚本、生成数据或仪表盘行为问题；
- 文档缺口；
- 公开安全贡献问题；
- 非商业工作流改造问题。

本项目不能提供：

- 敏感个人研究数据审查；
- 生产密钥或付费部署管理；
- 关于商业许可的法律意见；
- 通过公开问题处理紧急安全事件；
- 对第三方模型提供方在用户本地环境中的安全行为作保证。
