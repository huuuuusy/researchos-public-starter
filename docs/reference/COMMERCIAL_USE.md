# Commercial Use

ResearchOS Public Starter is available by default for personal learning, personal research, academic research, teaching, non-commercial evaluation, and non-commercial academic redistribution and derivative development. The canonical license is [LICENSE.md](../../LICENSE.md); where the Chinese explanation differs from it, the English license governs.

Academic redistribution, academic forks, and academic derivative development do not require separate written permission when they remain non-commercial, preserve the license and attribution, clearly mark material changes, do not include private ResearchOS materials, and do not imply official endorsement.

Commercial use and commercialization-adjacent large-scale distribution require separate prior written permission from Shiyu Hu. This includes, but is not limited to:

- integrating it into a paid product or internal commercial platform;
- providing paid deployment, consulting, or automation services for clients;
- distributing this project or derivatives as part of a commercial service;
- using the project as part of a paid workflow product, hosted service, or enterprise automation package;
- publishing, packaging, sublicensing, or redistributing modified versions, forks, dashboard variants, templates, or generated starter packs through a platform, marketplace, startup, consultancy, enterprise, or monetizable service channel;
- large-scale redistribution or derivative publication with a realistic commercial pathway, even if initially free;
- using substantial project content to train, fine-tune, benchmark, package, or provide commercial AI, developer, knowledge-management, workflow, or research-automation products or services.

The public starter does not grant rights to any non-public working materials, raw corpus, local runtime state, or private research memory.

Academic citation, classroom discussion, private non-commercial experimentation, academic redistribution, academic forks, non-commercial teaching adaptations, and linking to the official repository are allowed as long as they do not create a commercial service or commercialization-adjacent large-scale distribution.

To request written permission, use the contact details on the [maintainer's public website](https://huuuuusy.github.io/). Do not include confidential materials in an initial request.

## Reference Licenses Considered

The closest existing references are:

- [PolyForm Strict 1.0.0](https://polyformproject.org/licenses/strict/1.0.0/): useful as a source-visible reference, but too restrictive for this project's intended academic redistribution and derivative-development allowance.
- [PolyForm Noncommercial 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0/): useful for non-commercial software licensing, but it does not express this project's specific academic allowance plus commercialization-adjacent distribution gate.
- [Creative Commons BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/legalcode.en): useful for documents/media; the [Creative Commons FAQ](https://creativecommons.org/faq/#can-i-apply-a-creative-commons-license-to-software) recommends against using CC licenses for software itself.
- [Business Source License 1.1](https://mariadb.com/bsl11/): a source-available software reference, but it is designed around an eventual change to an open source license and does not match this project's current boundary.
- [Open Source Definition](https://opensource.org/osd): useful terminology reference; its field-of-endeavor requirements do not match this project's non-commercial and commercial-authorization boundary.

ResearchOS therefore uses a project-specific source-available research license rather than claiming one of these standard labels.
