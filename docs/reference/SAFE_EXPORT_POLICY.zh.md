# 安全导出政策

公开 starter 只允许导出公开安全内容。所有示例材料必须是虚构、清洗或明确授权公开的内容。

## 禁止放入

- 真实敏感人物、学生、合作者、评审或关系策略。
- 未公开论文细节、申请材料、审稿材料或内部项目策略。
- 原始语料、邮箱内容、聊天记录、本地路径、API 密钥或其他密钥。
- 来自非公开工作系统且未经过公开安全审核的仪表盘投影或运行日志。
- 其他私人系统的名称、路径、拓扑、能力目录、operator 标识、请求回执或 program state。
- 从其他私人系统复制的领域事实、身份记忆、人物关系或 authority。
- 未经人工确认却被写成确定知识的智能体输出。

如果不确定是否可以公开，默认不要加入公开版。

## 发布规则

公开发布应依赖虚构示例、已清洗材料、明确授权和验证脚本输出。一个文件在本地有用，并不代表它可以公开发布。

可复用的私人方法只能被独立重写为领域中性的通用原则。candidate-before-confirmation 和来源系统保留 authority 可以公开；私人 connector、能力目录、运行态和证据链不属于公开功能。
