# Safe Export Policy

The public starter may only export public-safe content. Demo materials must be fictional, sanitized, or explicitly approved for public release.

## Do Not Include

- Real sensitive people, students, collaborators, reviewers, or relationship strategy.
- Unpublished manuscript details, grant materials, review materials, or internal project strategy.
- Raw corpus, mailbox content, chat logs, local paths, API keys, or secrets.
- Dashboard projections or runtime logs from a non-public working system unless they have passed a public-safe review.
- Names, paths, topology, capability catalogs, operator identifiers, request receipts, or program state from sibling private systems.
- Domain facts, identity memory, relationship context, or authority copied from another private system.
- Unreviewed agent output presented as confirmed knowledge.

When unsure, keep the material out of the public version.

## Release Rule

Public release should be based on fictional examples, sanitized material, explicit permission, and validator output. A file being locally useful does not make it publishable.

A reusable private method may be described only as an independently rewritten, domain-neutral principle. Candidate-before-confirmation and source-retained authority are public-safe principles; the private connector, catalog, runtime, and evidence trail are not public features.
