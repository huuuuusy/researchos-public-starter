# 商业使用

ResearchOS Public Starter 默认允许个人学习、个人研究、学术研究、教学、非商业评估，以及非商业学术再分发和学术二次开发。正式许可文件是根目录的 [LICENSE.md](../../LICENSE.md)；如中文说明与英文许可存在差异，以英文许可为准。

学术再分发、学术 fork 和学术二次开发不需要单独书面许可，前提是保持非商业性质，保留许可和署名，明确标注实质修改，不包含私人 ResearchOS 材料，并且不暗示官方背书。

商业使用和具有商业化潜质的大规模分发需要事先取得 Shiyu Hu 的书面许可。包括但不限于：

- 集成进收费产品或内部商业平台；
- 为客户提供付费部署、咨询或自动化服务；
- 将本项目或其衍生版本作为商业服务的一部分分发；
- 将本项目用于收费工作流产品、托管服务或企业自动化方案；
- 通过平台、市场、创业项目、咨询服务、企业渠道或可货币化服务渠道，发布、打包、再授权或再分发修改版本、fork、仪表盘变体、模板或生成的 starter pack；
- 具有现实商业化路径的大规模再分发或派生版本发布，即使初期免费；
- 将本项目的实质内容用于训练、微调、评测、打包或提供商业 AI、开发者工具、知识管理、工作流或科研自动化产品/服务。

本仓库 不授予任何非公开工作材料、原始语料、本地运行状态或非公开研究记忆的使用权。

学术引用、课堂讨论、私人非商业实验、学术再分发、学术 fork、非商业教学改造和链接到官方仓库都是允许的，但不得形成商业服务或具有商业化潜质的大规模分发。

如需申请书面许可，请使用[维护者公开主页](https://huuuuusy.github.io/)上的联系方式。初次联系时不要附带保密材料。

## 参考过的现成协议

最接近的现成参考包括：

- [PolyForm Strict 1.0.0](https://polyformproject.org/licenses/strict/1.0.0/)：可作为 source-visible 参考，但对本项目希望允许的学术再分发和学术二次开发来说过于严格。
- [PolyForm Noncommercial 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0/)：适合非商业软件许可参考，但不能准确表达本项目“允许学术分发/二次开发，同时限制商业化潜质扩散”的边界。
- [Creative Commons BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/legalcode.en)：适合文档/媒体参考；[Creative Commons FAQ](https://creativecommons.org/faq/#can-i-apply-a-creative-commons-license-to-software) 不推荐把 CC 协议用于软件本身。
- [Business Source License 1.1](https://mariadb.com/bsl11/)：是 source-available 软件协议参考，但它通常包含未来切换到开源协议的设计，不符合本项目当前边界。
- [Open Source Definition](https://opensource.org/osd)：适合用来说明术语边界；其中不得限制使用领域等要求，与本项目保留商业授权门槛的边界不一致。

因此，本项目采用项目专用的 source-available research license，而不是直接声称使用上述某个标准协议。
