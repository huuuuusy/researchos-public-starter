# 文档

下面按新手需要的顺序排列。按问题选一份读，不必全部通读。

## 从这里开始

- [README](../README.zh.md)：ResearchOS 是什么，10 分钟能做什么。先读它。
- [首次上手说明](../08_exports/public_starter/onboarding-step-by-step.zh.md)：从演示走到自己的库的分步路线，写明每一步应该看到什么。第一次动手时照着走。

## 使用

- [用户手册](user-manual.zh.md)：说明里指向某一节，或者你想了解细节时，读那一节。第 1 节解释输出里的词，第 2 节讲在 Agent 客户端里走一个闭环，第 3 节讲会话调度器，第 4 节讲可选的 Dashboard，第 5 节讲用自己的材料，第 6 节讲安全。

## 理解与修改

- [系统参考](system-reference.zh.md)：改系统之前读。它定义状态、治理边界、内核与扩展架构、代码地图和目录。
- [AGENTS.md](reference/AGENTS.zh.md)：文件感知助手在这个仓库里先读的文件；想知道你的助手被告知了什么，就读它。

## 发布、扩展与贡献

- [治理与扩展指南](governance-guide.zh.md)：发布任何东西、自定义或扩展系统、安装插件或参与贡献之前读；许可也在这里。
- [`reference/`](reference/)：各份指南在需要时链接的政策：[Agent 协议](reference/AGENT_PROTOCOL.zh.md)、[上下文预算协议](reference/CONTEXT_BUDGET_PROTOCOL.zh.md)、[新材料放置规则](reference/WHERE_TO_PUT_NEW_MATERIALS.zh.md)、[安全导出规则](reference/SAFE_EXPORT_POLICY.zh.md)、[公开发布检查清单](reference/PUBLIC_RELEASE_CHECKLIST.zh.md)、[卡片成熟度与增强](reference/CARD_MATURITY_AND_ENHANCEMENT.zh.md)、[相关科研工具](reference/RELATED_RESEARCH_TOOLS.zh.md)和[商业使用条款](reference/COMMERCIAL_USE.zh.md)。
- 许可与社区政策：[许可](../LICENSE.md)在仓库根目录；[贡献](reference/CONTRIBUTING.zh.md)、[安全](reference/SECURITY.zh.md)和[支持](reference/SUPPORT.zh.md)政策的英文版也在根目录。想复用、参与贡献或报告问题时读。

## 背景

- [技术报告](technical-report.zh.md)（[中文 PDF](technical-report.zh.pdf) · [English PDF](technical-report.en.pdf)）：想知道架构为什么是这样、有什么证据支持时读。它包含正文第 1–5 节与附录 A–B；[补充说明 1–6](technical-report-supplement.zh.md) 放在 PDF 之外。报告描述的是私有原型，未经同行评审；实际行为仍由现行合同、几份指南和发布门禁约束。
- [V1.0.1 发布说明](releases/v1.0.1.zh.md)：相对 V1.0 改了什么。
- [V1.0 发布说明](releases/v1.0.0.zh.md)：V1.0 包含什么、还有哪些局限。
