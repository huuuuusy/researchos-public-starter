# 判断层

记录公开安全的决策示例和确认记录。不要加入真实审稿、申请、学生、合作或内部策略判断。

在你自己的库里，`personal_vault/02_decisions/` 每个值得留下的决定放一张卡：备选方案、为什么这样选、接受的风险。骨架：[`09_templates/basic/decision.zh.md`](../09_templates/basic/decision.zh.md)；示例：[决策卡](../examples/starter-cards/zh-CN/02_decisions/2026-09-22-wait-for-benchmark-v2.md)。
