# 身份层

记录公开安全的项目定位、原则和使用边界。不要在这里放入真实个人身份、机构关系或非公开履历。

在你自己的库里，`personal_vault/00_identity/` 放个人档案卡（`profile.md`，用 [`09_templates/basic/person.zh.md`](../09_templates/basic/person.zh.md)，`relationship_type: self`）和研究身份摘要（`research-identity.md`，用 [`09_templates/basic/research-identity.zh.md`](../09_templates/basic/research-identity.zh.md)），后者是助手最先读的入口。示例：[研究身份摘要](../examples/starter-cards/zh-CN/00_identity/research-identity.md)。
