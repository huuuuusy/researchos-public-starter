# New Project Intake Card Template

## Agent Summary

Use this template for early project seeds. The card should record source type, owner, one-sentence project idea, material paths, next step, promotion signal, risk, and sensitivity boundary. Do not turn a temporary idea into a confirmed project fact. Use `I0-I3` for incubation maturity; reserve `P0-P3` for priority.
