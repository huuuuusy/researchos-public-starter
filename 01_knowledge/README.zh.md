# 知识层

存放可公开的材料索引、阅读笔记和示例知识对象。公开版默认只使用虚构或已清洗材料。

在你自己的库里，`personal_vault/01_knowledge/` 的 `papers/` 放论文卡，`projects/` 放项目卡，`capsules/` 放方向摘要，骨架见 [`09_templates/basic/`](../09_templates/basic/README.zh.md)。示例：[论文卡](../examples/starter-cards/zh-CN/01_knowledge/papers/example-benchmark.md)、[项目卡](../examples/starter-cards/zh-CN/01_knowledge/projects/occlusion-tracking.md)、[方向摘要](../examples/starter-cards/zh-CN/01_knowledge/capsules/occlusion-tracking-capsule.md)。
