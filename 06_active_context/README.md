# Active Context Layer

This directory tracks the public demo state only. Keep it small and route-like.

Current product behavior belongs in the owner guides under `docs/` and `05_workflows/`. Version history belongs in `docs/releases/`; independently useful, public-safe migration evidence belongs in `07_archive/`. Do not add dated private-system audits or duplicate implementation checklists here.

Status rule:

| Status | Meaning |
| --- | --- |
| `active` | Current demo route or next step. |
| `supporting` | Background material for a specific surface or validator. |
| `superseded` | Historical evidence only; do not use as a new implementation checklist. |

Do not place real project state, private tasks, collaborator strategy, reviewer notes, or unpublished manuscript details in this repository.

Bounded presentation, meeting, application, analysis, or revision artifacts may live here only in a user's private/local vault while they have a named consumer, next action, or concrete waiting event. At closeout, follow the [Derived Work Artifact Lifecycle](../05_workflows/research_management/derived-work-artifact-lifecycle.md): distill durable content first, then archive only independently valuable history under `07_archive/task_artifacts/`.

This repository does not ship empty Dashboard inboxes. Personal-vault actions create local `ui-*` runtime files on demand; `.gitignore` keeps them out of the repository.
