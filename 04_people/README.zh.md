# 人物层

公开版只允许虚构人物或公开安全 persona，用于演示上下文治理。不要加入真实敏感人物或关系记录。

在你自己的库里，`personal_vault/04_people/collaborators/` 每位合作者一张卡，只写论文能说明的或你亲口说的，`sensitivity: sensitive`。骨架：[`09_templates/basic/person.zh.md`](../09_templates/basic/person.zh.md)；示例：[人物卡](../examples/starter-cards/zh-CN/04_people/collaborators/lin-ke.md)。
