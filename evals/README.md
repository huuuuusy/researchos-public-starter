# Evaluations

Stores public-safe validation examples and check notes. Evaluations should demonstrate boundaries and workflow, not expose private data.

Each test file puts `scripts/` on `sys.path` itself (`sys.path.insert(0, str(ROOT / "scripts"))`); a test that reuses another test file's fixtures also inserts the repository root and imports it as `evals.<name>`. So any file runs alone, from any directory, or under `python3 -m unittest discover -s evals`, in any order.
